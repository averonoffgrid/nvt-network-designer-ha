# NVT Designer v0.3 — Home Assistant model

## Stable identity
- NVT physical node -> HA Device
- HA Device identifier: `nvt_<96-bit UUID>`
- Entity unique ID: `nvt_<96-bit UUID>_<VAR_ID>`
- NODE_ID is an address and may change without creating a new HA device.

## Naming
The name edited in Designer is saved in `project.json`.
Every Deploy republishes MQTT discovery with that device name, so HA receives the updated node/device name.

## Commands from HA
Node 0 is reserved as SYSTEM / Home Assistant Gateway.
HA does not need a binding for ordinary entity control.

Writable HA entity:
HA -> MQTT command -> NVT Designer/Node0 -> DIRECT_WRITE(dst_node,var_id,value) -> target NVT node.

The target NVT node applies the variable locally and publishes its resulting EVENT/STATE back onto the NVT network.
The HA state is therefore confirmed from the node, not merely assumed optimistically.

## Virtual Node 0 variables
Node0 may also later expose virtual NVT variables (NightMode, AlarmArmed, HouseEmpty, etc.).
Those may participate in ordinary graphical bindings.
